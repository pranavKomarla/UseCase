# TeamFlow Lite Backend

Spring Boot backend scaffold using a layered architecture:

- Domain: Entities, enums, and business rules.
- Application: Use-case oriented services.
- API: REST controllers and DTOs.
- Infrastructure: Persistence, integrations, and scheduler hooks.

## Package Structure

- `com.teamflowlite.domain`
- `com.teamflowlite.application`
- `com.teamflowlite.api`
- `com.teamflowlite.infrastructure`

## Run

```bash
mvn spring-boot:run
```
